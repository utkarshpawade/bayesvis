Extended Bayesian Visualization: Diagnostics Beyond Trace Plots

bayesvis — vignette

This vignette is best viewed by building with devtools::build_vignettes() in an environment with Pandoc installed, or by running the Rmd file interactively in RStudio.

Overview

The bayesvis package extends bayesplot with diagnostic visualizations that complement the familiar trace plot. See vignettes/bayesvis.Rmd for the full source.

Functions

  • mcmc_shrinkage() — Prior-to-posterior shrinkage scatter
  • compute_shrinkage() — Compute shrinkage factors from draws
  • ppc_loo_pit() — LOO-PIT histogram with uniform band
  • ppc_loo_pit_qq() — LOO-PIT Q-Q plot with Beta envelope
  • mcmc_rank_ecdf() — Rank ECDF per chain with DKW bands
  • ppc_coverage() — Posterior predictive coverage plot
